Place /GAMEDATA and icon_ED.ICO from your Tonic Trouble install here. On a default Windows installation, the folder should be C:/Program Files(x86)/UbiSoft/Ed. A simple dump of the CD files won't work as these are stored as archives labeled tt1-4. In the future it might be possible to use these directly by decompiling InstallTT.exe and creating code to interpret those files.

Addendum: it's actually unclear what the files on the disc are; the disc also stores the exact same GAMEDATA folder as the installed files, but with these archives added in there as well. More investigation is required. Until then I believe the file extraction can be done with the install files; but it doesn't hurt to add the tt1-4 archives in there as well. Technically it's easier as it circumvents having to actually install the game. But these really ought to be encrypted archives of the game files, but then why are the plain files stored in there as well? Anyway...

The game converts all those files to a custom .ttlv format which TonicCore understands and renders. TonicViewer uses those bits to provide a native macOS experience, but you can write other graphics wrappers to target TonicCore.

TonicCore itself still needs a lot of work, it's firmly in the tech demo territory. If you'd like to keep working on this you also need TonicTrouble.exe and possibly other files as well. All the game logic is yet to be tackled, the menu system, basically everything. If you'd like to keep working on this just make sure you have all the game files ready. You can even attempt to load Rayman 2 levels into this (and my disc comes with a demo)... to end this digression, just make sure you have the /GAMEDATA folder in here at the very least.
