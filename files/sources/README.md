Place /GAMEDATA, /Demos (optional: the original demos, Replays menu) and icon_ED.ICO from your Tonic Trouble install here. On a default Windows installation, the folder should be C:/Program Files(x86)/UbiSoft/Ed. A simple dump of the CD files won't work as these are stored as archives labeled tt1-4. In the future it might be possible to use these directly by decompiling InstallTT.exe and creating code to interpret those files.

Optional: the Special Edition disc image (Tt.bin + Tt.cue, or an .iso) in any folder here, up to two folders deep. Its files are plain on the disc; the conversion copies them to se/ (docs/SE.md).
